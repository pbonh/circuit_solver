# circuit-solver documentation

Documentation sources for `circuit-solver`. The published docs split
by language frontend:

| Subdir         | Audience                                        | Tool                                  |
|----------------|-------------------------------------------------|---------------------------------------|
| `python/`      | Python users of `import circuit_solver`         | mkdocs + Material + mkdocstrings      |

Rust API documentation is generated by `cargo doc` and lives under
`target/doc/` after a `cargo doc --workspace --no-deps` build; it is
not part of the prose docs tree above.

## Quick start (Python docs)

```bash
cd python
mkdocs serve     # http://127.0.0.1:8000/
```

See `python/source/building.md` for the full build and CI story,
including how to flip on mkdocstrings autodoc once an importable
`circuit_solver` extension is available.
