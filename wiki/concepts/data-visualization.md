## Definition

Data visualization is the practice of representing data graphically so that patterns, trends, and outliers can be perceived quickly. The book pairs it tightly with data wrangling and descriptive analysis.

## How It Works

The book teaches data visualization in Python using Matplotlib (general-purpose plotting) and Seaborn (statistical visualization built on Matplotlib). Visualizations are produced inside Jupyter notebooks alongside the cleaning and analysis code.

## Key Parameters

- Chart type selection (histogram, line, bar, scatter, box, heatmap)
- Aesthetics (color, scale, axes)
- Statistical layer (regression lines, error bands)

## When To Use

- Exploratory data analysis to surface patterns and anomalies
- Communicating findings to non-technical stakeholders
- Case studies where temporal or spatial trends matter (e.g., the air-pollution example)

## Risks & Pitfalls

- Misleading axes / truncated scales
- Choosing chart types that obscure the data structure
- Overplotting in dense scatter plots
