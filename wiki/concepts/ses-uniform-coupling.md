## Definition

SES Uniform Coupling refers to a family of coupling-statement forms (all-to-all, all-to-one, one-to-all, each-to-each) that quantify over the entities generated by a multi-aspect, eliminating the need to enumerate individual port-to-port couplings.

## How It Works

The four canonical forms:
- `all X sends MSG to all X!` — every X output port couples to every other X input port, excluding self-coupling.
- `all X sends MSG to TARGET!` — all-to-one.
- `SOURCE sends MSG to all X!` — one-to-all.
- `each X sends MSG to each Y!` — pairs by matching prefix in the pruned name (e.g., tall_boy ↔ tall_girl).

Uniform-coupling forms are evaluated after multi-aspect restructuring, generating the actual port-to-port couplings at transformation time.

## Key Parameters

- Quantifier (all, each)
- Source and target entity types
- Message port name
- Matching key for each-to-each (entity prefix)

## When To Use

- Connecting populations of similar agents in a multi-aspect
- Broadcasts and gather patterns at scale
- Pairing entities by attribute via prefix matching

## Risks & Pitfalls

- each-to-each silently skips pairs without a matching prefix
- all-to-all excludes self-couplings — explicit self-loop requires extra coupling
- Mixed signal-domain ports must match types
