## What Marp Is

- Markdown-driven slide deck format
- Frontmatter (`marp: true`) flips a markdown file into a deck
- Rendered locally via the Marp CLI or VS Code extension; no proprietary tooling required

---

## How Decks Integrate With The Wiki

- One deck per topic at `wiki/presentations/<topic-slug>.md`
- Generated by `/wiki-present <topic>` — finds relevant pages via `wiki/index.md`, stitches their key claims into slides
- Always cites every source page on the final References slide as a wiki link
