## Overview

Pandas is the Python data wrangling library. The book devotes a chapter ("Prepping Your Data with Pandas") to cleaning, reshaping, and analyzing tabular data with it.

## Characteristics

- `Series` and `DataFrame` data structures built on NumPy
- Labeled indexing, alignment, joining, and reshaping
- Time-series support
- Reading/writing CSV, Excel, SQL, JSON

## Common Strategies

- Use DataFrames as the canonical in-memory table
- Chain cleaning and transformation steps
- Pair with Matplotlib/Seaborn for visualization
