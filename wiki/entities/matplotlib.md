## Overview

Matplotlib is Python's foundational plotting library, used by the book for general-purpose visualization in the data analysis chapters and case studies.

## Characteristics

- Imperative and object-oriented APIs (`pyplot` and Figure/Axes)
- Supports line, bar, scatter, histogram, boxplot, image, contour, and 3D plots
- Backends for interactive and static rendering
- Foundation for Seaborn and Pandas plotting

## Common Strategies

- Quick plots with `pyplot` for exploration
- Object-oriented API for multi-panel, publication-quality figures
- Pair with Seaborn for statistical aesthetics
