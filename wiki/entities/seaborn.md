## Overview

Seaborn is a statistical visualization library built on top of Matplotlib. The book introduces it alongside Matplotlib in its data visualization chapter.

## Characteristics

- High-level API for statistical plots (regression, distribution, categorical, matrix)
- Themes that improve default Matplotlib aesthetics
- Works directly with Pandas DataFrames
- Built-in support for hue/style/grid faceting

## Common Strategies

- Use for distribution and relational plots (e.g., `histplot`, `boxplot`, `scatterplot`, `lmplot`)
- Combine with Matplotlib for fine-grained customization
- Pair with Pandas DataFrames for tidy-data inputs
