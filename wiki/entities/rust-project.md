## Overview

The Rust Project is the open-source community and governance body that develops the Rust programming language, its compiler (`rustc`), build tool (`cargo`), and supporting tooling. Stewardship has been transferred to the Rust Foundation, with day-to-day work performed by topic subteams (Language, Compiler, Library, Infrastructure, Documentation, etc.) and a large body of volunteer contributors.

## Characteristics

- Six-week stable release cadence, three release channels (nightly, beta, stable)
- RFC-based feature design with public discussion
- Multiple topic subteams making consensus decisions
- Sponsored by the Rust Foundation
- Distributed maintenance via GitHub (`rust-lang/rust`)
