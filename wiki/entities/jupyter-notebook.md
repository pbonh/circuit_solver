## Overview

Jupyter Notebook is an interactive web-based environment for running code, prose, and visualizations in a single document. The book delivers all code as Jupyter notebooks readers can adapt and extend.

## Characteristics

- Cell-based execution (code, Markdown, raw)
- Inline rich output (figures, tables, HTML)
- Kernel-backed sessions in Python and other languages
- Common environment for exploratory data analysis

## Common Strategies

- Iterate on cells during EDA
- Embed plots and prose alongside analysis steps
- Share notebooks for reproducible reporting
