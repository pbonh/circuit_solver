## Overview

SciPy is a Python library for scientific and statistical computation. The book uses it to simplify tedious statistical calculations (probability distributions, hypothesis tests, integration, optimization).

## Characteristics

- Submodules for statistics (`scipy.stats`), optimization, integration, linear algebra, interpolation, signal processing
- Built on top of NumPy
- Statistical tests including ANOVA, chi-squared, t-tests, and z-tests

## Common Strategies

- Use `scipy.stats` functions for canonical statistical tests
- Pair with NumPy/Pandas data structures
- Bridge into scientific workflows beyond data analysis
