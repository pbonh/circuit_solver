## Overview

NumPy is the Python scientific computation library that provides multi-dimensional array objects and fast vectorized math operations. The book devotes a chapter to working with NumPy arrays as the foundation for downstream analysis.

## Characteristics

- N-dimensional `ndarray` data structure with homogeneous dtype
- Vectorized arithmetic and broadcasting
- Linear algebra, random sampling, FFT, and statistics utilities
- Underpins Pandas, SciPy, scikit-learn, and Matplotlib

## Common Strategies

- Use arrays instead of Python lists for numerical work
- Leverage broadcasting to avoid explicit loops
- Combine with Pandas for tabular work and SciPy for advanced stats
