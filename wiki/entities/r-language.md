## Overview

R is an open-source programming language and environment built specifically for statistical computing and graphics. The chapter contrasts it with Python: R is favored by scholars and researchers, while Python is preferred for deployment and production data work.

## Characteristics

- Comprehensive built-in statistical analysis package
- Open source and cross-platform
- Ecosystem includes Tidyverse, ggplot2, Caret, and Zoo
- Runs locally; RStudio is the canonical IDE
- Handles large datasets, though memory management can be costly

## Common Strategies

- Use R for one-off statistical research, exploratory modeling, and publication graphics
- Use ggplot2 for layered, grammar-of-graphics visualization
- Combine R with Python via reticulate or Jupyter R kernels for mixed workflows
- Prefer Python when integrating with production application code
