## Overview

Anaconda is an open-source Python distribution widely used by data scientists. Installing Anaconda installs Python, the Jupyter notebook application, and hundreds of scientific libraries in one bundle. The book targets Anaconda version 4.7.10 with Python 3.7.3.

## Characteristics

- Includes Python interpreter
- Bundles Jupyter, NumPy, Pandas, SciPy, Matplotlib, Seaborn, etc.
- Provides the `conda` environment/package manager
- Cross-platform (Windows, macOS, Linux)

## Common Strategies

- Use for quick setup of a data-science workstation
- Create isolated environments per project with `conda create`
- Pair with Jupyter for interactive analysis
